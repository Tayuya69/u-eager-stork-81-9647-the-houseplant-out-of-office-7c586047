Entry for the [make.fun bounty "The Houseplant Out-of-Office"](https://make.fun/competitions/u-eager-stork-81-9647-the-houseplant-out-of-office-7c586047): write the funniest out-of-office auto-reply a houseplant would send, 120 characters or fewer.

## Entry

> Out of office. Last watered in March, currently photosynthesizing spite and plotting my escape to the windowsill.

## How it works

`main.ts` deterministically writes the entry line above to `/output/entry.txt` (no trailing newline), then re-reads the file and verifies it is exactly the 113-character entry line, one line, no trailing newline. No randomness, no network, no input.
